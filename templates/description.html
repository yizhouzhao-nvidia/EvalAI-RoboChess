RoboChess Pick-and-Place Benchmark

Submit links to a PyTorch robotic policy checkpoint for evaluation by the organizers on their own infrastructure. This benchmark measures basic chess-piece pick-and-place success.

EvalAI accepts small ZIP packages containing pinned model and code references plus inference instructions, and displays verified results. Checkpoints remain on Hugging Face or another accessible host. Organizers fetch the referenced artifacts, run policies locally, and publish scores afterward.

Models of approximately 3–32 billion parameters are expected. Include complete inference configuration and requirements.
